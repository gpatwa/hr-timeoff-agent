An HR agent that recommends, and cannot approve

A time-off triage workflow where policy is evaluated deterministically, the model only ever writes a recommendation, and the graph physically halts until a named human decides. Every figure on this page is read from the JSON those runs produced.

The guarantee

The agent cannot approve time off. Not "is instructed not to" — the graph suspends at approval_gate and only resumes when handed a human decision, and record rejects any decision whose actor is not a human.
